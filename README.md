# nespadron.github.io

## Push local `main` to GitHub

```bash
cd /path/to/nespadron.github.io
git remote add origin https://github.com/nespadron/nespadron.github.io.git
git push -u origin main
```

If `origin` already exists, update it first:

```bash
git remote set-url origin https://github.com/nespadron/nespadron.github.io.git
```
